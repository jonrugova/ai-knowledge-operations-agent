# Public Repository Checklist

Complete this checklist immediately before publishing:

- [ ] No secrets, API keys, passwords, session secrets, or database URLs are present.
- [ ] `.env` and other local environment files are ignored.
- [ ] Private company documents are absent from the publishable file set.
- [ ] Real approvals and executions are absent.
- [ ] Real traces and customer data are absent.
- [ ] Screenshots have been reviewed and contain no private information.
- [ ] Evaluation datasets are fictional or sanitized.
- [ ] Fictional sample knowledge is present.
- [ ] Frontend build succeeds.
- [ ] Offline tests pass.
- [ ] `git status` has been reviewed.
- [ ] `git diff` has been reviewed.
- [ ] No private company or customer information was found in candidate files.
- [ ] No API keys, passwords, or database URLs are committed.
- [ ] No GitHub repository has been created or pushed to without explicit approval.
